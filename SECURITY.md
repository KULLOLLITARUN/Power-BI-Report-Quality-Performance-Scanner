# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability in `pbiscan`, please do not open a public GitHub issue.

Instead, please report it directly by opening a private security advisory on GitHub or by contacting the maintainer via [GitHub profile](https://github.com/KULLOLLITARUN).

We appreciate your efforts to responsibly disclose findings and will work to address verified issues promptly.
